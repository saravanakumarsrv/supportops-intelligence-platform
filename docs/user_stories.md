# User Stories

## Support Manager

As a support manager, I want to see SLA breach rate by department so that I can improve staffing and routing decisions.

## Support Agent

As a support agent, I want high-risk tickets prioritized so that I know which customers need urgent attention.

## Operations Analyst

As an operations analyst, I want root-cause analysis by issue type so that I can recommend process improvements.

## Customer Experience Leader

As a customer experience leader, I want to monitor customer sentiment so that I can reduce churn and improve satisfaction.
